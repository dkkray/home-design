# Backyard Patio Redesign

Concept package for redoing the back-of-house patio: new concrete with a kidney-shaped
extension, a matte-black attached **Pergolux** louvered pergola replacing the old awning,
and a stucco + light-stone re-clad on the backyard wall.

## View it
Open **`index.html`** in any browser. It's self-contained (inline CSS/SVG) — no build step.

## What's inside
- **The brief** — decisions captured from our conversation.
- **Existing conditions** — reference photos in `assets/`.
- **Material & color palette** — stucco, light stone, matte black, warm concrete.
- **Look & feel** — perspective concept of wall + pergola + floor.
- **Option A — "The Soft Kidney"** — one continuous sweeping space (budget-first).
- **Option B — "Two-Zone Sweep"** — separate dining + lounge "rooms" (phase-2 ready).
- **Master plan (left side)** — shed removal, fence push, gym pod (future phase).
- **Planting palette** — Front Range / Zone 5, low-water.
- **Scope & phasing** — foundational now, fire feature / gym pod later.

## Design brief (locked)
| Topic | Decision |
|---|---|
| Style | Modern: black pergola, stucco + lighter stone wall |
| Pergola | Attached, matte black (awning footprint) |
| Patio shape | Kidney extension into the yard |
| Concrete | Full run along back wall + replace side slabs; remove rock bed |
| Zones | Dining + lounge |
| Budget | Foundational now; bigger moves phased |
| Left side (future) | Remove shed, push fence forward, add gym pod |
| Site | L-shaped split-level; mature shade tree kept at patio edge |
